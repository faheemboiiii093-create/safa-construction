SAFA CONSTRUCTION INTRO AUDIO

safa-cinematic-intro.wav is an original sound-design asset made for this website.
It layers a restrained sub-bass pulse, a rising architectural synth bed, a precise
metallic logo impact, and a spacious, fading tonal tail. It is an uncompressed,
stereo 22.05 kHz PCM WAV, with no third-party samples, recordings, or music.

The recording is original to SAFA CONSTRUCTION and may be used with this website.
Intro playback always attempts to start with sound. If browser autoplay restrictions
block it, the intro waits for the visitor to choose its visible play-with-sound control.
Background music is not used. The separate sound toggle controls optional interface
feedback only; its preference is stored locally.
